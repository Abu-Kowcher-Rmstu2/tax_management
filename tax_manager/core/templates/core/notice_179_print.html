যেহেতু উপরিউক্ত করবর্ষের আয়কর ধার্য প্রসঙ্গে আয়কর আইন, ২০২৩ এর ধারা ১৬৬, ১৭৫ বা ১৭৬ অনুযায়ী আপনি একখানি আয়কর রিটার্ন দাখিল করিয়াছেন/ ধারা ১৭২ বা ২১২ অনুযায়ী {{ notice_data.notice_date|default:"" }} খ্রি. তারিখ যুক্ত একটি নোটিশ {{ notice_data.served_date|default:"" }} তারিখে আপনার উপর জারী করা হইয়াছে, উক্ত আইনের ধারা ১৭৯ অনুযায়ী আপনাকে অবহিত করা হইতেছে যে, নিম্নস্বাক্ষরকারীর অফিসে {{ hearing_date_bn }} তারিখ {{ hearing_time_bn }} ঘটিকায় নিম্নবর্ণিত হিসাব বহি/দলিলাদি দাখিল করিবেন।

এই নোটিশ পরিপালনে ব্যর্থ হইলে আয়কর আইন, ২০২৩ এর ধারা ২৭০ অনুযায়ী জরিমানা আরোপের বিধান রহিয়াছে।
